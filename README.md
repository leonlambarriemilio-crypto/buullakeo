# Buullakeo

Página de la fiesta de Halloween Buullakeo (sábado 24 de octubre).

- `index.html`: página para invitados (pedir lugar, mandar comprobante, ver el boleto).
- `taquilla/`: Taquilla de organizadores (entra con usuario y contraseña).

Los datos viven en una hoja de Google y se leen a través de un Google Apps Script que funciona como API.
